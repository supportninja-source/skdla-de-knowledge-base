Incisive Model Selection Visual Guide

Visual tooth-range and model-selection reference for Incisive cases. Incisive cases do not use Mini models; use Quadrant or Full Arch according to the rules below and any applicable Doctor Preference/account-specific instruction.

← Back to Knowledge Base
Core Incisive rule: Do not select Mini. Use Quadrant or Full Arch. Always check Doctor Preferences and explicit account-specific rules before finalizing the model.

Anterior tooth ranges

Teeth 6–11 and 22–27 are anterior. For an Incisive anterior/incisor case, use Full Arch.

Highlighted teeth from the supplied guide

Anterior + posterior two-tooth example

If the Rx requests two teeth and the combination includes anterior and posterior as shown in the guide, select Full Arch.

Example highlights: teeth 9 and 20

Three posterior teeth on opposing sides

If three posterior teeth are positioned on opposing sides, select Full Arch.

Example highlights: teeth 3, 4, and 13

Two posterior teeth on the same arch

If two posterior teeth are on the same arch / next to each other, select Quadrant.
